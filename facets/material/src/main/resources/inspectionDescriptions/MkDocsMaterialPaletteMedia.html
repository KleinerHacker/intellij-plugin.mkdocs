Reports a media of theme.palette that is none of the media queries Material for MkDocs is built around.

The value is handed to the media attribute of the style sheet the theme renders, so every query a browser accepts is legal here. The theme itself is built around three of them: (prefers-color-scheme: light), (prefers-color-scheme: dark) and (prefers-color-scheme) for the palette of the system preference.

A query outside them decides nothing the colour scheme toggle of the theme can act on: the palette is either always active or never, and both look like the palette being ignored. There is no quick fix — which of the three was meant is not something the file says.
