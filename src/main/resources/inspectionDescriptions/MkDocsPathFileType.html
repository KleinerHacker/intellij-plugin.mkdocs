Reports a path in an MkDocs configuration file naming a file of a type the key cannot use.

Some keys do something specific with the file they point at: extra_css loads it as a style sheet, extra_javascript as a script, and theme.logo and theme.favicon render it as an image. A file of another type exists just as well, so the path resolves and nothing else marks it — while the built site loads a page as a style sheet.

Example:


extra_css:
  - stylesheets/extra.md

The value has to name a style sheet instead:


extra_css:
  - stylesheets/extra.css

A value carrying no extension at all is not reported: below theme.logo and theme.favicon the Material theme accepts the name of one of its own icons, such as material/library, which is not a path.
