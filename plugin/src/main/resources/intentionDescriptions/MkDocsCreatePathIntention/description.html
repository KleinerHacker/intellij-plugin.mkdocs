Creates the target a path value of mkdocs.yml points at.

The value is resolved the way MkDocs resolves it — docs_dir, site_dir and theme.custom_dir against the configuration file, everything else against docs_dir — the missing directories along the way are created, and a directory or an empty file is put at the end of it. The value itself is left exactly as written.

Not offered for site_dir: that directory is build output, and creating it by hand only produces an empty directory MkDocs would have written itself.
