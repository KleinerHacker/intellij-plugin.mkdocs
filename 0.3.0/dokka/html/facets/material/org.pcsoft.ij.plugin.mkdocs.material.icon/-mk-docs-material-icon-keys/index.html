MkDocsMaterialIconKeys

object MkDocsMaterialIconKeys

The places a configuration file of Material for MkDocs names an icon at.

Two features ask the same question and must never answer it differently: the completion offering the icon names, and the inlay hint painting the drawing in front of a name already written. So the paths live here and nowhere else.

Decided on the whole path, never on the name of the nearest key: below theme.icon the key is the element the icon is put on — repo, edit, menu — while the other places end in icon themselves.
