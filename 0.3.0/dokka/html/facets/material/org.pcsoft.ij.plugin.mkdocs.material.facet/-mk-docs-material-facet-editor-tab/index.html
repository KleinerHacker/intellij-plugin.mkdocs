MkDocsMaterialFacetEditorTab

class MkDocsMaterialFacetEditorTab(configuration: MkDocsMaterialFacetConfiguration) : FacetEditorTab

The overview tab of the Angular Material facet.

The tab is informational: the theme is declared in mkdocs.yml, and the facet mirrors it. What the user can do here is add or remove the facet itself, which is handled by the dialog rather than by this tab. The settings of the theme live on the four tabs next to this one (MkDocsMaterialSettingsEditorTab).
