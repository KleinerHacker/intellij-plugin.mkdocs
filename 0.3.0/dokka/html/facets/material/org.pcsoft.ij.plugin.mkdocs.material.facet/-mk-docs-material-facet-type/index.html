MkDocsMaterialFacetType

class MkDocsMaterialFacetType : FacetType<MkDocsMaterialFacet, MkDocsMaterialFacetConfiguration>

Registration of the Angular Material facet with the platform.

Declared in plugin.xml via com.intellij.facetType. The facet belongs to an MkDocs site, but it is not declared as a sub facet of the MkDocs facet: the platform is doing away with nested facets (IDEA-309067, "Get rid of nested (child) facets"), and the only way to nest is a constructor deprecated for that reason. The connection between the two is therefore kept by the site detection of the plugin, which only ever adds this facet next to an MkDocs facet and drops it together with it.

Since the tree no longer shows what belongs to what, the name and the icon have to. The facet is called MkDocs Angular Material, so it reads as part of MkDocs and sorts next to the MkDocs facet in the flat list, and its icon is the MkDocs logo itself with the Material glyph badged into the corner — the same relation the tree used to draw, now drawn in the icon.
