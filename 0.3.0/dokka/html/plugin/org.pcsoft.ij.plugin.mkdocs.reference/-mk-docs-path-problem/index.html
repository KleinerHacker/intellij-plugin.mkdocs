MkDocsPathProblem

enum MkDocsPathProblem : Enum<MkDocsPathProblem>

What can be wrong with a path written into an MkDocs configuration file.

The distinction the entries carry is not "bad" against "worse" but "broken here" against "broken elsewhere". A configuration file travels: it is written on one machine, built on the continuous integration of another and checked out by whoever contributes a page. A path the current operating system refuses is an error, a path only some other operating system refuses is a warning — reported, because it will break the build of somebody else, but not marked as broken on a machine where it works.
