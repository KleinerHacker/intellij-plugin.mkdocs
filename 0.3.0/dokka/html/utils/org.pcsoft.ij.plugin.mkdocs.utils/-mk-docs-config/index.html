MkDocsConfig

object MkDocsConfig

Reads the few pieces of information the module system needs out of an MkDocs configuration file.

Parsing goes through the bundled YAML plugin's PSI instead of a YAML library: the PSI is already built and cached by the IDE, it tolerates the half-written files an editor sees, and it keeps the plugin free of an extra runtime dependency.

Only what MkDocs itself defines is read here. Which theme a name stands for, and what a theme brings with it, is the business of the feature offering that theme — see isTheme.

All functions here must be called inside a read action.
