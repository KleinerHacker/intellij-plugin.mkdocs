MkDocsConfigEditScope

class MkDocsConfigEditScope

The operations of MkDocsConfigWriter bound to one project and one configuration file.

Handed to the block of MkDocsConfigWriter.edit. None of these functions commits — the whole batch is committed once when the block returns.
