MkDocsProject

object MkDocsProject

Recognition of MkDocs project files by name.

This is intentionally a pure, platform-independent helper: it answers questions about file names only, so it can be unit-tested without booting the IntelliJ Platform. Anything that needs a VirtualFile, a Project or PSI belongs in a separate, platform-aware layer on top of this.
