MkDocsMaterialWizardStep

class MkDocsMaterialWizardStep(materialFeature: MkDocsMaterialSiteFeature, page: MkDocsMaterialSettingsPage) : MkDocsFeatureWizardStep

One Material settings page shown as a page of the site creation wizard.

The step owns nothing: it hands the page's component to the wizard, and on the way out it folds what the page collected into the settings of the feature instance this wizard is filling in. The very same page object appears as a tab of the Angular Material facet, which is why the step has to stay this thin — any behaviour added here would exist in the wizard and be missing in the Project Structure dialog.

materialFeature
