MkDocsSchemaFileProvider

class MkDocsSchemaFileProvider : JsonSchemaFileProvider

The mapping itself: the MkDocs schema for every file named mkdocs.yaml.

No schema file is shipped with the plugin. The schema is named as a remote source instead, which is what the platform uses for every catalogue entry as well — it is downloaded once and cached, and it stays in step with the schema mkdocs.yml is validated against instead of ageing inside the plugin.
