MkDocsFacet

class MkDocsFacet(module: Module, name: String, configuration: MkDocsFacetConfiguration, underlyingFacet: Facet<*>?) : Facet<MkDocsFacetConfiguration>

Marks a module as containing an MkDocs site.

This is the anchor of the whole MkDocs module system: everything that is optional about a site — Angular Material, I18N, Mike — is meant to be added later as its own facet declaring ID as its underlying facet type, exactly like framework facets stack on a Java module.

Parameters

module

the module the facet belongs to

name

the facet name shown in Project Structure

configuration

the persistent facet state

underlyingFacet

always null — the MkDocs facet is a root facet
